# ZimOsaka AutoSpares advertising posters

This set contains 20 individual 4:5 vector posters for digital sharing and high-quality print scaling. `index.html` previews the full set and provides individual SVG downloads. The SVGs are self-contained designs with local image references; keep the adjacent `assets/` folder when moving or sharing the files.

Open `print-all.html` in a browser and choose **Print / save as PDF** for a 20-page A4 portrait set. The posters are centered on each A4 sheet with white margins. `generate-posters.js` regenerates the designs and gallery.

Engine photos are illustrative, not current stock listings. Exact engine specification, availability and final price must be confirmed by quotation. The set intentionally omits an unverified phone number, website URL and QR code. See [CREDITS.md](./CREDITS.md) for image authors, source pages and licenses.
