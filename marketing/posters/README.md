# ZimOsaka AutoSpares advertising posters

This set contains 20 individual 4:5 vector posters for digital sharing and high-quality print scaling. `index.html` previews the full set and provides individual SVG downloads. Each SVG embeds its illustrative photo, so posters can be moved or shared individually. Keep the adjacent `assets/` folder to regenerate the set.

Social-ready 1080 × 1350 PNG exports are available in `png/`.

All 20 posters use poster 09's full-bleed engine photo, navy overlay and gold-accented treatment. The customer journey shown is: request an engine → we check suppliers in Dubai → if it is unavailable, our team searches local garages → after the customer approves the quote and pays the deposit, an available engine is reserved → we process shipment → after arrival in Zimbabwe, fitting is available through our trusted mechanic. ZimOsaka does not hold engine stock. Mechanic fitting is a separate service; the posters do not imply that installation is included in the engine or shipping quote.

Open `print-all.html` in a browser and choose **Print / save as PDF** for a 20-page A4 portrait set. The posters are centered on each A4 sheet with white margins. `generate-posters.js` regenerates the designs and gallery.

Photos and engine-model references are illustrative examples, not current stock listings or a promise of availability. Exact specification, availability and final price are confirmed after a request. The set intentionally omits an unverified phone number, website URL and QR code. See [CREDITS.md](./CREDITS.md) for image authors, source pages and licenses.
